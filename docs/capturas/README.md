# Capturas pendientes de una sesión real

El entorno del agente bloquea puertos y lanzamiento del navegador. No se inventaron capturas. En Fase 9, iniciar backend y frontend y guardar aquí PNG de:

1. `01_operaciones.png`: barra, seis recursos, proceso y lista de espera.
2. `02_manual.png`: registro de cliente y pedido con varias líneas.
3. `03_almacen.png`: mapa, inspector de ubicación y lote no contiguo.
4. `04_recepcion.png`: patio, cola de mensajes y existencias.
5. `05_deadlock.png`: alerta, grafo real y elección de ganador.
6. `06_resolucion.png`: ambos pedidos finalizados y unidades recuperadas.
7. `07_metricas.png`: gráficas y SLA por nivel.
8. `08_comparador.png`: configuración 42/300/4 y cuatro resultados.
9. `09_conexion.png`: sondeo o aviso de desconexión.

Relacionar cada imagen con las secciones 3–9 del Manual de Usuario, agregar referencias Markdown y regenerar los PDF con `python scripts/generar_manuales.py`. Los SVG de `docs/diagramas` son diagramas, no capturas.
